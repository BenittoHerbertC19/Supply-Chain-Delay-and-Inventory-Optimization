SUPPLY CHAIN POWER BI PACKAGE

Files:
1. Supply_Chain_PowerBI_Data.csv
   - 2,000 rows
   - 25 columns
   - Power BI-ready source data

2. PowerBI_DAX_Measures.txt
   - KPI measures for the dashboard

HOW TO USE:
1. Open Power BI Desktop.
2. Select Home > Get Data > Text/CSV.
3. Select Supply_Chain_PowerBI_Data.csv.
4. Load the data.
5. Create the DAX measures from PowerBI_DAX_Measures.txt.
6. Build the KPI cards and dashboard using these measures.

Suggested KPI cards:
- Total Orders
- Delayed Orders
- On Time Orders
- Delay Rate %
- Total Order Value
- Average Lead Time
- Average Delay Days
- Supplier Performance %

Suggested visuals:
- Orders by Delivery Status
- Delayed Orders by Supplier
- Delay Days by Category
- Inventory Status
- Order Value by Category
- Monthly Orders Trend
