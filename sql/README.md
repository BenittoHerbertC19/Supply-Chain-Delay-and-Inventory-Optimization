# SQL Analysis

This folder contains the MySQL scripts used for the Supply Chain Delay & Inventory Optimization project.

## Files

1. `01_database_setup.sql` - Creates the MySQL database.
2. `02_create_orders_table.sql` - Creates the Orders table.
3. `03_supplier_analysis.sql` - Analyzes supplier performance and delays.
4. `04_product_analysis.sql` - Analyzes product delivery delays.
5. `05_inventory_analysis.sql` - Analyzes inventory and reorder levels.
6. `06_warehouse_analysis.sql` - Compares warehouse performance.
7. `07_transportation_cost_analysis.sql` - Analyzes transportation costs.
8. `08_monthly_delivery_analysis.sql` - Analyzes monthly delivery trends.
9. `09_supplier_product_analysis.sql` - Finds problematic supplier-product combinations.
10. `10_kpi_analysis.sql` - Calculates overall supply-chain KPIs.

## Database

Database: `supply_chain`

Main table: `Orders`

## Tool

MySQL Workbench
